# Araç Defteri

Modern Android araç günlüğü demo projesi.

## Demo kapsamı
- Yenilikçi açık / koyu / sistem teması
- Araç profili ve kilometre
- Bakım / onarım kayıtları ve değişen parça açıklaması
- Hasar kayıtları ve fotoğraf / belge eki
- Ekspertiz kayıtları ve rapor eki
- Sigorta / kasko, muayene ve vergi kayıtları
- Yakıt ve diğer gider kayıtları
- Araç fotoğraf galerisi
- Tarih bazlı 7 gün ve 1 gün kala bildirimler
- PDF Araç CV üretimi
- Cihaz içi SQLite veri saklama

Bu depo kişisel veri içermez. İlk kurulumdaki Toyota Corolla ve geçmiş kayıtları yalnızca demo verisidir.
